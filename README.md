# princeton_2026_rix-nix

"But it works on my computer", is a common saying. Being able to reproduce the work of others is a cornerstone of the scientific endeavor. Recent technological advances have made computational reproducibility increasingly attainable; however, widespread adoption remains limited, particularly in psychology. One reason is that reproducibility exists on a continuum. At one end is partial transparency, such as sharing analysis scripts along with package names, software versions, and other information needed to understand how an analysis was conducted. At the other end are fully executable research compendia that can regenerate results from raw data and code within the exact computational environment used at the time the research was conducted.

To support what I refer to here as computational reproducibility, a growing number of tools and workflows have been developed, each with its own strengths, limitations, and practical tradeoffs. In this talk, I will discuss some of the challenges involved in achieving computational reproducibility and introduce Nix, together with the rix R package, as an approach for managing both software-package and system-level dependencies. I will show how these tools can be used to create reproducible computational environments that remain stable over time, helping researchers move beyond documenting their analyses toward making them truly executable and reproducible.
